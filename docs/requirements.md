# Skill 灵感站 — 需求与页面结构

## 1. 网站定位

帮助普通用户发现 GitHub 上真实、受关注的 Agent Skill：按用途筛选，了解功能、适用工具、来源和安装方式。

- 目标用户：对 Agent Skill 感兴趣的普通用户与开发新手。
- 内容原则：只收录可核实的真实 Skill；中文简介依据原始说明归纳；安装方式必须来自官方文档。
- 部署形态：纯静态网站，可托管到任意静态平台（GitHub Pages / Cloudflare Pages / Vercel 等）。

## 2. 技术方案

- React 19 + TypeScript + Vite 8，路由使用 react-router（HashRouter，静态托管无需服务端配置）。
- 无后端、无数据库、无登录注册投稿支付。
- 搜索 / 分类 / 排序全部在浏览器端完成。
- 数据分两类分开保存：
  - `public/data/skills.json`：人工整理的内容（中文简介、分类、安装说明、来源链接）。
  - `public/data/repos.json` + `meta.json`：同步脚本生成的 GitHub 指标（Stars / Forks / 最近推送 / 归档状态 / 同步时间）。
- 同步脚本 `scripts/sync-github.mjs`（Node，无第三方依赖，令牌只从环境变量读取）。
- 定时更新：GitHub Actions 每天一次，仅在数据变化时提交。

## 3. 页面结构

| 路由 | 页面 | 内容 |
| --- | --- | --- |
| `#/` | 首页 | 站名与简介、搜索框、用途分类、编辑精选、Skill 卡片列表、匹配数量 / 清除条件 / 空结果提示 |
| `#/rankings` | 排行 | Stars 榜、最近更新榜（均按仓库去重，可展开查看仓库下已收录 Skill）、新收录榜（按收录日期）；明确标注"基于本站已收录项目" |
| `#/skill/:id` | Skill 详情 | 名称、中文简介、主要用途、使用示例、适合人群、作者与所属仓库、目录直链、适用工具、仓库指标、按工具区分的安装步骤（含复制按钮与反馈）、许可证、数据同步日期与内容核实日期 |
| `#/guide` | 新手指南 | 什么是 Agent Skill、如何挑选、如何看适用工具与安装说明、安装前的安全提醒 |

公共元素：顶部导航（首页 / 排行 / 新手指南）、页脚（GitHub 数据最后成功同步时间、免责声明）。

## 4. 搜索与筛选规则

- 搜索范围：名称、中文简介、作者（仓库）、标签。
- 英文忽略大小写，忽略前后空格；搜索与分类可组合。
- 展示匹配数量，提供一键清除；无结果时给出提示。

## 5. 分类

编程开发 / 设计创作 / 写作办公 / 数据分析 / 效率工具。

## 6. 卡片字段

名称、中文用途、适用工具、分类、所属仓库 Stars（标注为"所属仓库 Stars"，不暗示单技能使用量）。点击进入详情。

## 7. 数据更新规则

- 同一仓库只请求一次，合集内多个 Skill 共用仓库数据。
- 同步失败 / 限流：保留上一次成功数据，记录失败原因，不用零值覆盖，不把旧数据标成刚更新。
- 指标有变化才更新该仓库记录；全部成功才刷新"最后成功同步时间"。

## 8. 视觉规范

浅色背景、深色文字、蓝色主色；搜索和分类突出；卡片留白合理；无大片渐变与过度动画；适配桌面与手机（无横向滚动，长命令仅在代码区内滚动）；按钮 / 链接 / 输入框支持键盘操作并有可见焦点。

## 9. 非目标（第一版不做）

登录注册、投稿、评论、在线支付、独立后端与数据库、今日涨星榜 / 本周增长榜（无历史快照，不编造增长数据）。
